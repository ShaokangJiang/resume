# Shaokang Jiang's academic website and résumé

Three site versions share the existing content engine:

- `index.html`: modern homepage with the introduction, published first-author papers (including arXiv preprints unless under review), and compact education. Generated by the actual [al-folio](https://github.com/alshedivat/al-folio) theme (`al_folio_core` 1.0.15), Jekyll, and Jekyll Scholar. The theme supplies the layouts, typography, styles, publication cards, and fonts.
- `publications/index.html`: modern complete publication list, including coauthored papers and manuscripts under review.
- `experience/index.html`: modern research, teaching, and industry experience, with Research selected by default.
- `projects/index.html`: modern detailed projects and technical skills.
- `pure.html`: plain HTML using browser defaults and no custom CSS, with the complete paper list and résumé sections.
- `rabbit.html`: original illustrated résumé design, based on [Simple-CV](https://github.com/dcetin/Simple-CV), with the current introduction and shared publication renderer.
- `pdf.html`: existing PDF viewer; direct downloads use `final/research/Shaokang_Jiang_Resume.pdf`.

Edit `js/site-data.js` for the introduction, contact links, and modern/pure education entries. The research focus is end-user programming and personal software, connected with developer tools and programming assistants.

All versions use the original shared publication database, `pub.bib`. The modern Publications page, pure page, and rabbit page show the complete list, including manuscripts marked under review. The modern homepage shows first-author papers with a public record, including arXiv preprints, and excludes entries marked under review, submitted, unpublished, or in preparation. `js/publication-policy.js` applies the same rule during compilation and live rendering; use the BibTeX `status` or `note` field to record review status. Experience and projects use `experience-source.js` and `project-source.js`; the modern Projects page and pure page also read `Skills.tex`. No publication thumbnails are required. The rabbit page retains its education, skills, project gallery, experience timeline, and original navigation header.

Access the three versions directly at `https://shaokangjiang.github.io/resume/`, `/resume/pure.html`, or `/resume/rabbit.html`. There are no page-switch links. The modern site uses al-folio's default header with only about, publications, experience, projects, and cv as page links, in that order, plus the search and light/dark theme controls. Publications, Experience, and Projects have separate pages, and CV opens the PDF viewer. The pure page has no navigation bar. The rabbit page keeps its original desktop section links, mobile side menu, blog button, and PDF button. The modern Experience page, pure page, and rabbit page filter experience through All, Research, and TA & Work buttons; project preview buttons on the rabbit page open dialogs within the current page.

The modern page uses al-folio's compiled bibliography when it matches `pub.bib`. If the bibliography changes before the next build, the browser refreshes the paper rows using the same theme markup. All other résumé sections continue to render from the shared sources on page load.

To rebuild the modern page on Windows, run `./scripts/build-modern.ps1` from PowerShell. It uses native Ruby/Bundler when available, otherwise the installed Ubuntu WSL distribution. Node.js and Ruby 3.2 or later with Bundler are required. The configured Ubuntu build uses the official Ruby 3.3.12 binary in `/opt/hostedtoolcache/Ruby/3.3.12/x64`; it does not replace system Ruby. Dependencies are isolated in `modern/vendor/bundle` for native Ruby or `~/.cache/resume-al-folio/bundle` inside Ubuntu; the exact versions are recorded in `modern/Gemfile.lock`.

The build prepares the shared data, runs `bundle exec jekyll build`, audits local theme overrides, and copies the four modern pages and theme assets to the repository root. The copy step converts local resource and navigation URLs to relative paths at each page's directory depth so the same output works at both `/` locally and `/resume/` on GitHub Pages; canonical URLs remain the GitHub Pages addresses. Shared scripts and styles receive content hashes to refresh browser caches after a rebuild. `modern/upstream-config.yml` retains the official starter defaults; `scripts/prepare-modern.js` writes the personal configuration and derived bibliography without changing the original sources. Edit templates in `modern/_pages/` rather than the generated HTML files.

The default navigation header, about layout, name treatment, bibliography layout, Sass, fonts, and runtime scripts come from the official theme packages, with no local theme overrides. `modern/_plugins/navigation.rb` supplies the site's navigation destinations to the default header without generating placeholder pages. `css/al-folio-content.css` arranges the existing résumé entries and offsets section anchors below the fixed header; it does not replace the theme typography or publication styling. Roboto font files are served locally with their upstream license.

The local BibTeX reader in `js/bibtex.js` supports braced and quoted fields, nested braces, escaped percent signs, line comments, and concatenated values. The source files remain compatible with the existing Node.js résumé generators.

Serve the repository over HTTP so the browser can load the bibliography and skills, for example `python -m http.server 8000`. Open `http://localhost:8000/`, `/publications/`, `/experience/`, `/projects/`, `/pure.html`, or `/rabbit.html`. The same files also work under `/resume/` on GitHub Pages. Opening files directly with `file://` prevents browsers from fetching the content sources.

The content updates from the shared sources on page load. Rebuild the modern page after changing its template, theme configuration, or dependencies. PDF files are separate generated artifacts; linking them does not regenerate them.
